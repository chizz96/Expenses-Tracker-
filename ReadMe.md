Expense Tracker API

A RESTful API built with Node.js and Express.js for managing personal expenses. It uses a local JSON file as its data storage, making it a simple project for learning backend development, CRUD operations, REST API design, and file handling.

FEATURES
Record a new expense.
View all expenses.
View a particular expense.
Update an expense.
Delete an expense.
a logger that log all the request
Persist records in a JSON file.

TECHNOLOGIES USED
Node.js
Express.js
JavaScript (common js)
JSON file storage


REQUIRMENTS
Before running the project, ensure you have installed:

Node.js (which includes npm)
Postman or another API client for testing

INSTALLATION AND SETUP

Clone the repository
git clone https://github.com/chizz96/Expenses-Tracker-.git

Navigate into the project directory:
cd expense-tracker-api

Install dependencies
npm install Or npm i

Run the project
npm run dev

Built as a backend development learning project.
